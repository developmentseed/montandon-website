# Data Examples

This page will provide documentation and examples for fetching and working with data in the Montandon database.

Please refer to these notebooks for examples of how to access and use the data: <https://ifrcgo.org/montandon-notebooks/>

## Reference documentation

Montandon items follow the Monty STAC extension, which is specified and documented in [`monty-stac-extension`](https://github.com/IFRCGo/monty-stac-extension). Rather than restate it here:

- [Monty data model](https://ifrcgo.org/monty-stac-extension/model/) — how events, hazards, impacts and response products relate, and the [taxonomies](https://ifrcgo.org/monty-stac-extension/model/taxonomy/) that classify them.
- [Source analyses](https://ifrcgo.org/monty-stac-extension/model/sources/) — for each source on the [Data Sources](/methodology/data-sources) page, how its records map onto that model and which collections it produces.
- [Validated examples](https://ifrcgo.org/monty-stac-extension/examples/) — a real item for every collection, checked against the schema on each commit.
